# 요트 다이스 🎲

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 요트 다이스. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **규칙**: 주사위 5개를 한 차례에 **최대 3번** 굴린다. 첫 굴림 뒤에는 남길(고정) 주사위를 눌러 두고 나머지만 다시 굴린다. 굴린 뒤 점수 칸 12개 중 아직 안 쓴 칸 하나에 점수를 적는다(0점도 적어야 하고, 한 번 적은 칸은 못 바꾼다). 12번씩 적으면 끝, 합계가 큰 쪽이 이긴다(같으면 무승부)
- **점수 칸**: 1~6의 눈(그 눈의 합) · 초이스(다섯 개 합) · 포카드(같은 눈 4개 이상이면 다섯 개 합) · 풀하우스(3+2 이면 다섯 개 합) · 스몰 스트레이트(4개 이어짐 15) · 라지 스트레이트(5개 이어짐 30) · 요트(다섯 개 모두 같으면 50). 1~6의 눈 합이 63 이상이면 보너스 35점
- 화면: 점수표 두 칸(왼쪽 1~6 + 보너스, 오른쪽 나머지 + 합계)에 나와 상대 점수가 나란히 보인다. 굴린 뒤 안 쓴 칸에는 **지금 주사위로 받을 점수**가 흐리게 뜨고, 칸을 눌러 고른 뒤 **✔ 적기**. 고정한 주사위는 위로 올라간다. **상대가 방금 적은 칸**은 주황 테두리로 깜빡이고 메시지로도 알려 준다
- 컴퓨터: 쉬움은 가장 많이 나온 눈을 모으고 마지막에는 그 순간 점수가 가장 큰 칸에 적는다(가끔 아무렇게나). 어려움은 남은 굴림만큼 앞을 내다보는 기댓값 계산(눈 묶음 252가지 전수, 칸마다 평소 기대 점수를 빼서 아깝지 않게 적고, 보너스 문턱도 계산)을 한다. 어려움이 쉬움을 크게 이긴다(시험으로 확인)
- 컴퓨터를 이긴 횟수는 `yachtWins` (로비 표시용), 내 최고 점수는 `yachtBest`, 온라인 전적은 `yachtOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 한 차례 60초(넘기면 시간패) · 기권 · 한 판 더(선후 교대). **주사위는 서버가 굴리고**(조작 방지) 규칙 검사도 서버가 같은 코드(`public/logic.js`)로 한다. 차례가 아니거나 굴림이 남지 않았거나 이미 쓴 칸이면 무시. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다

규칙과 컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(점수 계산·굴림 규칙·보너스·컴퓨터·시드 고정 대전), `test/server.test.js`(서버를 띄워 매칭·입력 검사·굴림/고정/점수·24차례 한 판·기권·시간 초과·재접속).
